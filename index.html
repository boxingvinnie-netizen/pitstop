Pitstop

A free Windows app for PC gamers. It finds what is slowing your games, fixes it safely, and tells you which upgrade is worth the money.

Check an upgrade See what it checks

What Pitstop checks

Most gaming PCs are a few settings away from the speed their owner paid for. Pitstop reads your hardware and Windows, explains each finding in plain English and fixes what is safe to fix.

Hardware that is set up right

RAM running below its rated speed, memory in one channel, a 165 Hz monitor left at 60 Hz, a graphics card in a slow slot, a nearly full system drive.

Each one is shown with what you have, what it should be, and how to fix it.

Real FPS, measured while you play

Average FPS with 1% and 0.1% lows, from Windows' own frame events. Measure, change one thing, measure again.

Pitstop also tells you whether each game is held back by the graphics card, the CPU or a frame cap.

Startup and background apps

Every startup item with a plain verdict, its publisher's signature and what it costs at sign-in. Security software is locked and cannot be switched off.

The Background tab shows which apps use CPU, RAM and graphics memory while you game.

Windows gaming settings

Game Mode, GPU scheduling, variable refresh rate, background recording and the power plan, checked against your hardware.

No registry folklore: only settings with a measurable effect.

Safe by design

First it only reads. Nothing changes until you press Fix.

Pitstop starts read-only and explains every finding before offering anything.

Then it makes a restore point and changes only what you chose.

It uses Windows' own switches, the same ones Task Manager uses. Risky items need two confirmations.

Every change is logged, with one-click Undo.

Undo any change later from History, or roll the whole PC back with the restore point.

Questions

Is Pitstop free? Yes. The app and every check in it are free, with no account and no adverts.

When can I download it? Pitstop is being tested now. The first public download will be published on this page.

Which PCs does it work on? Windows 10 and 11 desktops and laptops, with NVIDIA, AMD or Intel graphics.

Can it break my PC? It only changes things you confirm, makes a restore point first and logs every change with Undo. It does not overclock, install drivers or edit the BIOS.

Does it speed up my PC by itself? No. It finds the real problems, such as RAM below its rated speed or a monitor at the wrong refresh rate, and shows how much each fix is worth.

What leaves my PC? Nothing about your PC. With live prices switched on, only part names and barcodes are sent to the price services. You can turn online features off.

Where do the prices come from? From UK shops' own product feeds and APIs. Without them, Pitstop shows typical prices and links to each shop's search.

Do the shop links earn money? Some can, through affiliate programmes. That pays for Pitstop and never changes which price is shown as cheapest.

Does it slow games down? No. In the tray it uses about 21 MB of memory and almost no CPU, and the window can be closed while you play.

Does this website track me? No. It sets no cookies and runs no analytics. Shop links lead to the shops' own websites, which have their own privacy policies.
